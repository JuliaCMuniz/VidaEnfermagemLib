# Interface DialogueListManagerInterface

Interface que contém os métodos chamados pelos itens da lista de perguntas do diálogo para efetivar alterações em um item da lista. Contém as funções:

1. OnDialogueChanged: para mudança do valor da pergunta;
2. OnDialogueDeleted: para remoção da pergunta;
3. GetDialogueAnswers: para buscar todas as respostas da pergunta;
4. AddAnswerToDialogue: para adicionar uma resposta vazia à pergunta.

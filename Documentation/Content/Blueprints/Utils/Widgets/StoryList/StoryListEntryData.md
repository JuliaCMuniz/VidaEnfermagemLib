# Struct StoryListEntryData

Contém o struct com os dados necessários para a exibição dos elementos da lista de histórias da cena:

* SelectedStoryClass: String correspondente ao nome da classe da história, mapeada para o tipo da classe durante a instanciação da história;
* SelectedStoryAnchor: tag da âncora associada à história;
* StoryIndex: index da história, utilizado para operações de Get e Set.

# Pasta Syringe

Contém os blueprints e meshes referentes às diferentes partes da agulha para o procedimento de coleta, além de conter o blueprint com todas as meshes montadas para a forma final da agulha. Uma composição análoga dessas meshes foi implementada no projeto atual. Será importante realizar a reconstrução da lógica de montagem da agulha de acordo com o procedimento padrão.
